🎯 Project Objective:
========================

The primary objective of this project is to analyze historical temperature data and understand how Bangalore's average temperature has varied across different years.

Key objectives:
===============

- Load and inspect the Bangalore weather dataset.
- Identify missing values in the weather observations.
- Handle missing numerical values using mean imputation.
- Convert the date column into a proper datetime format.
- Extract year, month, and day from the date.
- Calculate the average temperature for each year.
- Present the yearly temperature results in a structured form.
- Visualize the historical temperature pattern.

---

📂 Dataset:
=============

The project uses the following dataset:

`Bangalore_1990_2022_BangaloreCity.csv`**

The dataset contains historical weather observations for Bangalore City.

Weather Variables

| Column | Description |
|---|---|
| `time` | Date of the weather observation |
| `tavg` | Average temperature |
| `tmin` | Minimum temperature |
| `tmax` | Maximum temperature |
| `prcp` | Precipitation |

The analysis covers the period from **1990 to 2022**. :contentReference[oaicite:3]{index=3}

🧹 Data Cleaning:
==================

Missing values in the numerical weather columns are handled using **mean imputation**.

The following columns are processed:

- `tavg`
- `tmax`
- `tmin`
- `prcp`

Each missing value is replaced with the mean of its respective column.

After preprocessing, the missing-value check shows zero missing values in these columns. :contentReference[oaicite:5]{index=5}

Why Mean Imputation?

Mean imputation provides a simple way to replace missing numerical observations while retaining the existing records in the dataset.
