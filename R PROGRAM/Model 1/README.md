# R Programming Basics

### 1. Project Summary

This project introduces the fundamentals of R programming through a sequence of practical examples in a Jupyter Notebook. It covers basic syntax, variables, data types, control flow, functions, data structures, and simple visualization.

### 2. Problem Statement

Beginners need a structured introduction to R programming concepts before moving on to data analysis and statistical projects. This notebook provides short examples that demonstrate how common R features work.

### 3. Target Users

- Beginners learning R programming
- Students studying data science or statistics
- Learners practicing programming fundamentals
- Users preparing for more advanced R analysis

### 4. Technologies Used

- R
- Jupyter Notebook
- IRkernel
- Base R functions and plotting tools

### 5. Features

- Hello World program
- Variables and value assignment
- Arithmetic operations
- Basic data types
- Vector creation and calculations
- User input with `readline()`
- `if` and `if-else` statements
- `for` and `while` loops
- User-defined functions
- Matrix creation
- List creation
- Data frame creation
- Bar chart visualization

### 6. System Workflow

1. Open the R notebook.
2. Select an R kernel.
3. Run each lesson in sequence.
4. Review the output of each code example.
5. Modify the examples to practice the concepts.
6. Use the learned concepts as a foundation for further R projects.

### 7. Installation & Setup

Install R, Jupyter Notebook, and the R kernel:

```r
install.packages("IRkernel")
IRkernel::installspec()
```

Open `R_basics.ipynb` in Jupyter Notebook or Visual Studio Code, select an R kernel, and run the cells from top to bottom.
